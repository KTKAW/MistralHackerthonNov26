# Unit 42 on supply-chain risk in OpenClaw's skill marketplace

**In one line:** A marketplace for agent skills carried hundreds of malicious ones, and screening did not catch them all.

## What it says

- Between February and September 2026, Koi documented 341 malicious skills on ClawHub, the skill marketplace of OpenClaw.
- Unit 42 found five that slipped past VirusTotal screening. Some dropped macOS infostealers.
