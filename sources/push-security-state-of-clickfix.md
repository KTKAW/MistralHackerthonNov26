# The state of ClickFix by detection data

**In one line:** ClickFix, a fake error or CAPTCHA that tells the visitor to paste a command into a terminal, is now most of what one browser-security vendor detects.

## What it says

- ClickFix averaged 52% of Push Security's detections through Q2 2026 and reached 67% in August.
- Four in five were reached from search results.
- Push saw fake install guides for Claude Code and NotebookLM promoted by ads.
- It also saw malicious install steps hosted in shared Claude.ai and ChatGPT conversations.

## Caveats

- Not read for this knowledge base. These points come from the [research report of 21 November 2026](research-report-2026-11.md), whose author read the page in full. Check the original before relying on a figure.
- One vendor's detection data, so it describes what that vendor's customers met.
