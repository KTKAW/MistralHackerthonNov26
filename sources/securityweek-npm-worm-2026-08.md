# SecurityWeek on the August 2026 npm worm

**In one line:** A self-spreading npm attack infected hundreds of packages within hours and went after developer tokens.

## What it says

- In August 2026 a worm pushed more than 2,200 malicious versions of 440 packages in under four hours.
- It stole npm, GitHub and cloud tokens.
- It planted Claude and VS Code config files for persistence.
