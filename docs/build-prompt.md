## 1. Mission

Build the system designed in `docs/architecture.html`: paste a security advisory → one headless
Vibe agent per repository runs in a sandbox → each returns a gated `verdict.json` → a web grid
shows one tile per repo live → a draft 24-hour CRA Art. 14 early warning is produced and **pauses
for a human approve signal**. A human, never the tool, submits anything to ENISA.

Pipeline (one Mistral Workflows run):

```
intake (24h clock starts) → read advisory (1 model call → advisory.json)
→ triage (asyncio.gather, one activity per repo, heartbeat 10s, ONE attempt, fresh work copy)
→ verify (rules gate as code, no model) → report (early-warning.md from gated verdicts only)
→ wait for "approve" signal (24h timeout)
```

## 2. Non-negotiable rules (violate none of these, ever)

- **Never commit secrets.** `.env`, `vibe-home/`, `runs/`, `wheelhouse/` go into `.gitignore`
  **before any code lands** (Step 0). The Mistral API key lives in `.env` inside `VIBE_HOME`.
- **Scope rules:** proof tests only against our own demo code, in an isolated sandbox. Only
  publicly known flaws. Proof inputs must be harmless (create an empty marker file, or get a
  forged request accepted). Never post anything to third-party issue trackers automatically.
- **Agent prompt rules** (learned from the 21 Nov test runs): (1) change nothing in a repository
  found not affected; (2) never delete or weaken a test; (3) never edit the installed library.
- **Web tools are off** in every worker: `--disabled-tools connector_web_search_web_search
  --disabled-tools connector_web_search_open_url`. Packages come **only** from the local
  wheelhouse via `pip --no-index --find-links wheelhouse`.
- **"Not affected" is worded "no reachable path found", never "safe"**, and always cites the code
  path followed.
- **The gate may only downgrade a verdict to `needs_human`** — never upgrade.
- **The grid shows a tile only after the gate has run.** An unchecked claim never appears as a result.
- **One attempt per activity.** A retry on a half-changed work copy would be wrong, so each
  activity gets a fresh copy under `runs/<run>/<repo>/src/` and `retry_policy_max_attempts=1`.
- Pin **Vibe 3.1.3** (hooks only tested on it). Sandbox is **macOS `sandbox-exec`** (Linux `bwrap`
  is out of scope for the demo). Set `OTEL_ENABLED=false` so the worker sends no logs/traces.
- The tool **never sends anything to ENISA**; a person submits the report.

## Step 3 — Shell sandbox: `sandbox2.py` hook → `douane` → `sandbox-exec`

Goal: every shell command Vibe runs goes through the wrapper; in the 21 Nov test, 47/47 commands
ran inside the sandbox.

- [ ] Create `sandbox/sandbox2.py` — a Vibe `pre_tool` hook (ADAPT to the exact Vibe 3.1.3 hook
  interface). Contract: when the tool is `bash` / `process_start`, rewrite its command to
  `douane <original command>`; pass everything else through untouched. Strict mode: if the
  rewrite fails, **deny** the call rather than letting it run unsandboxed.

```python
#!/usr/bin/env python3
"""sandbox2.py — pre_tool hook. Rewrites every shell command to run through douane."""
import json, os, sys

DOUANE = os.path.join(os.path.dirname(os.path.abspath(__file__)), "douane")
SHELL_TOOLS = {"bash", "process_start"}

def main() -> int:
    payload = json.load(sys.stdin)          # ADAPT: match Vibe 3.1.3 hook I/O contract
    tool = payload.get("tool", "")
    if tool in SHELL_TOOLS:
        cmd = payload.get("args", {}).get("command", "")
        if not cmd:
            return deny("empty command")
        payload["args"]["command"] = f"{DOUANE} {quote(cmd)}"
    print(json.dumps(payload))              # ADAPT
    return 0

def deny(reason: str) -> int:
    print(json.dumps({"deny": True, "reason": reason}))
    return 1

def quote(s: str) -> str:
    return "'" + s.replace("'", "'\\''") + "'"

if __name__ == "__main__":
    sys.exit(main())
```

- [ ] Create `sandbox/douane` (executable):

```sh
#!/bin/sh
# douane — run a command with a scrubbed environment inside the macOS sandbox.
# Vibe passes its .env contents to shell children; env -i stops that leak.
set -eu
DIR="$(cd "$(dirname "$0")" && pwd)"
WORKDIR="${SANDBOX_WORKDIR:?SANDBOX_WORKDIR must point at the work copy}"

exec env -i \
  HOME="${HOME:-/Users/$(whoami)}" \
  PATH="/usr/local/bin:/usr/bin:/bin:/usr/sbin:/sbin" \
  TMPDIR="${TMPDIR:-/tmp}" \
  LANG="${LANG:-C.UTF-8}" \
  SANDBOX_WORKDIR="$WORKDIR" \
  sandbox-exec -f "$PROFILE" /bin/bash -c "$*"
```

You are triaging ONE repository in an isolated, sandboxed work copy at `src/`.
The advisory facts are in `../advisory.json` (id, package, affected_range, flawed_function).

```python
"""run_repo.py — prepare a fresh work copy and run one headless Vibe against it."""
import os, shutil, subprocess, sys, threading, time, json

def run_repo(run_id: str, repo: str, fleet_root: str, runs_root: str, vibe_home: str) -> dict:
    work = os.path.join(runs_root, run_id, repo)
    src = os.path.join(work, "src")
    shutil.copytree(os.path.join(fleet_root, repo), src)          # fresh copy — one attempt only
    # venv + vulnerable version from the wheelhouse, offline
    subprocess.run([sys.executable, "-m", "venv", os.path.join(work, ".venv")], check=True)
    pip = os.path.join(work, ".venv", "bin", "pip")
    wh = os.path.abspath("wheelhouse")
    subprocess.run([pip, "install", "--no-index", "--find-links", wh, "-r",
                    os.path.join(src, "requirements.txt")], check=True)

    env = dict(os.environ)
    env.update({
        "VIBE_HOME": os.path.abspath(vibe_home),
        "OTEL_ENABLED": "false",
        "SANDBOX_WORKDIR": src,
    })
    cmd = [
        "vibe",
        "--workdir", src, "--trust",
        "--prompt-file", os.path.abspath("worker/prompt.md"),
        "--model", "mistral-large-4-0",
        "--output", "text", "--output-dir", os.path.join(work, "vibe"),
        "--max-turns", "80", "--max-price", "3", "--time-limit", "560",
        "--disabled-tools", "connector_web_search_web_search",
        "--disabled-tools", "connector_web_search_open_url",
        "--auto-approve",
    ]
    proc = subprocess.Popen(cmd, env=env)

    stop = threading.Event()
    def heartbeat():                                   # ADAPT: call workflows.activity_heartbeat
        while not stop.wait(10):
            try:
                heartbeat_fn()                         # workflows.activity_heartbeat(...)
            except Exception:
                pass
    t = threading.Thread(target=heartbeat, daemon=True); t.start()
    rc = proc.wait()
    stop.set()

    verdict = json.load(open(os.path.join(work, "verdict.json")))
    export = json.load(open(os.path.join(work, "vibe", "export.json")))
    return {"repo": repo, "rc": rc, "verdict": verdict, "export": export}
```

import asyncio, os
from mistralai import Workflows  # ADAPT to mistralai-workflows 3.20.0

wf = Workflows()  # ADAPT

@wf.workflow("le_chonk_run")
async def run(advisory_text: str):
    run_id = wf.run_id  # ADAPT

    gated = await verify(run_id, verdicts)                 # gate as code (Step 7)
    report = await report(run_id, gated)                   # early-warning.md (Step 8)
    await wf.wait_for_signal("approve", timeout_hours=24)  # ADAPT: pause for a human
    return report

@wf.activity
def read_advisory(advisory_text: str) -> dict:
    # exactly one chat API call to mistral-large-4-0 returning
    # {id, package, affected_range, flawed_function}; write runs/<run>/advisory.json
    ...

@wf.activity(activity_opts=dict(  # ADAPT option names
    start_to_close_timeout=900, heartbeat_timeout=60, retry_policy_max_attempts=1))

## Step 7 — The gate as code (`orchestrator/gate.py`)
