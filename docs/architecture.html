System design

One advisory goes in. One Le Chonk agent per repository decides whether the flaw can be reached, proves it with a test, and fixes it. Out come a verdict per repository and a draft of the 24-hour early warning. The orchestrator is a Mistral Workflows workflow. On 21 November 2026 we ran the core path for real: three agents in parallel inside one workflow, each returning a correct verdict that we then re-checked by hand. The web page, the gate and the report are designed here but not built yet.

In production

This is not for the hackathon. It shows how the same design would run at an enterprise, entirely inside the company's own cloud account or data centre, model included if they want that.

Not decided or not tested yet

  • How many agents at once. Three ran in parallel with no rate-limit errors. Ten has not been tried.
  • The path hook. It must block file-tool writes outside src/ and reads of .env and secrets/. Until it exists, the sandbox only covers the shell.
  • A crash during a Vibe run. A run did resume after we killed the worker, but only after the activity's timeout. Whether the heartbeat shortens that is untested.
  • The gate as code. Its checks were run by hand so far.
  • Mistral Agents for the advisory reader. The Agents SDK could return the advisory facts as a typed result. Not tried.
  • Vibe version. The hooks were only tested on 3.1.3. Stay on it unless 3.1.4 is tested first.
  • Which real open-source project joins the fleet, and who checks by hand that its flaw triggers.
